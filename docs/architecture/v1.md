# Proposal: V1 — Order Management Core

## Goal
Stand up the order domain as a standalone Go + PostgreSQL API. No Salesforce, no cloud deployment, no async processing yet.

## Scope
- Order entity: create, retrieve, list, status transitions (`created → approved → fulfilled`)
- Customer and product as minimal supporting entities (no config/pricing logic)
- REST API, tested via curl/Postman
- PostgreSQL schema with migrations

## Out of scope
- Salesforce integration (V2+)
- AWS deployment (later stage)
- Auth, async processing, analytics — not until a concrete need forces them

## Definition of done
- API runs locally, persists to Postgres, passes basic tests for each state transition
